## Let There Be Light v0.1.1 Beta

### Fixed
- **Eye adaptation no longer flickers on and off.** It now works through Skyrim's own adaptation instead of changing brightness every frame.
- **Moonlit nights are no longer pitch black.** Adaptation now measures the whole screen again, so moonlight, sky and every visible light count.

- **NPC torches now appear in hand and light the area.** Torches are equipped immediately and the NPC's model refreshes so the torch and its light attach.

### How eye adaptation works now
- Skyrim's adaptation measures the scene; LTBL controls the timing: glare settles in 1 to 10 seconds by brightness, and darkness adapts over 20 to 90 seconds by how dark it is.
- New **Timing calibration** slider in case adapting feels faster or slower than the seconds shown.
- The character-measured mode from v0.1.0 is still available as **Experimental: measure at character**, off by default.

### Install
Install `LetThereBeLight-v0.1.1-beta.7z` with Mod Organizer 2, replacing v0.1.0. Requires SKSE and Address Library for SKSE Plugins. Disable any ENB or separate Community Shaders install.
